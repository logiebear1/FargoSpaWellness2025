# Fargo Spa & Wellness – Final Project (Fall 2025)

CSCI 213 – Modern Software Development

GitHub Repo: https://github.com/logiebear1/FargoSpaWellness2025

## Features Implemented
- Responsive spa-themed UI with Bootstrap 5
- User registration & login (Individual Accounts)
- Browse & book appointments (requires login)
- Submit testimonials (admin approval workflow)
- Contact form with database storage
- Full Admin Dashboard (admin@fargospa.com / Admin123!)
  - Manage services (toggle active/inactive)
  - Approve/delete testimonials
  - View all bookings

## Technology Stack
- .NET 9.0
- Blazor Server (Interactive Server rendering)
- Entity Framework Core + SQL Server LocalDB
- ASP.NET Core Identity with Roles
- Bootstrap 5 + Bootstrap Icons

## Default Accounts
- **Admin**: admin@fargospa.com / Admin123!
- Regular users can register normally
